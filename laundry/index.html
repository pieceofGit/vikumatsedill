Reminders
until I mark it finished

This page beeps, vibrates and shows a notification while it's open. Phones pause pages that are in the background or have the screen off, so turn on phone reminders below if you want to be nagged while you're doing something else.

1. Install the free ntfy app (Android or iPhone).
2. In the app, subscribe to the topic on ntfy.sh. The topic name is private to you, so keep it to yourself.
3. Send a test notification to check it arrives.

When a machine starts, the reminders are booked on ntfy.sh straight away: one when it should be done, then one every interval for the next 3 hours. Marking it finished cancels the rest. The Emptied it button on the phone notification opens this page and does the same.

Start with Siri

A shortcut can book the reminders itself, in the background, without opening anything. They arrive in the ntfy app, so set up Phone reminders through ntfy under Reminders first. The text below has your topic filled in.

“ started”

In Shortcuts tap +, give it a name Siri won’t mistake for a smart-home command, e.g. “ started”, and add these actions in order. Use Copy and paste where it says to.

  1. Ask for Input: leave the type as Text, prompt “For how long?”
  2. Get Numbers from Input: this picks the 90 out of “90 minutes”, so you can answer Siri naturally (always in minutes).
  3. Text: paste
  4. Split Text: set it to split by Spaces.
  5. Repeat with Each item in Split Text. Put steps 6 and 7 inside it, before End Repeat.
  6. Calculate: Repeat Item + Numbers (tap the number and pick Numbers).
  7. Get Contents of URL. In the URL box, build it from three pieces:
    1. paste
    2. insert the Repeat Index variable (above the keyboard)
    3. paste
    4. insert the Calculation Result variable
    5. paste
    Then tap › (Show More) and set Method to POST.

Say the shortcut’s name to Siri and answer with the minutes, e.g. “90 minutes”, and you're done. Nothing opens. Reminders come at that time and then every min for 3 hours. Their Emptied it button stops the rest.

“ emptied” (optional)

Stops the reminders by voice:

  1. Repeat times. Put step 2 inside it.
  2. Get Contents of URL: paste , then insert the Repeat Index variable. Under Show More, set Method to DELETE.

If you change the topic or the reminder interval, the shortcuts need these texts copied again.
