    This page beeps, vibrates and shows a notification while it's open. Phones pause pages that are in the background or have the screen off, so turn on phone reminders below if you want to be nagged while you're doing something else.

    1. Install the free ntfy app (Android or iPhone).
    2. In the app, subscribe to the topic on ntfy.sh. The topic name is private to you, so keep it to yourself.
    3. Send a test notification to check it arrives.

    When a machine starts, the reminders are booked on ntfy.sh straight away: one when it should be done, then one every interval for the next 3 hours. Marking it finished cancels the rest. The Emptied it button on the phone notification opens this page and does the same.

    Start with Siri

    Say “Hey Siri, washing machine started”, answer “2 hours” or “90 minutes”, and the reminders get booked. Nothing opens. Set up Phone reminders through ntfy under Reminders first: the reminders, and a “timer set” confirmation, arrive in the ntfy app. Expect the confirmation within about 5–15 minutes. The countdown starts from when you spoke to Siri, so the reminders still come on time.

    Starting

    In Shortcuts, make a shortcut named what you'll say to Siri (e.g. “Washing machine started”) with just two actions:

    1. Ask for Input: type Text, prompt “For how long?”
    2. Get Contents of URL: tap the address box, paste then, with the cursor at the very end, tap Provided Input above the keyboard.

    Already have a “Washing machine started” shortcut? Delete everything except Ask for Input, then do step 2.

    Emptied (optional)

    A second shortcut, e.g. “Washing machine emptied”, with one action:

    1. Get Contents of URL: paste

    Or tap Emptied it on a reminder, or Finished here. The page shows a machine started with Siri as running.

    Reminders come every min (your setting when you copied the address). If you change the topic or interval, copy the addresses again.
