Reminders
until I mark it finished

This page beeps, vibrates and shows a notification while it's open. Phones pause pages that are in the background or have the screen off, so turn on phone reminders below if you want to be nagged while you're doing something else.

1. Install the free ntfy app (Android or iPhone).
2. In the app, subscribe to the topic on ntfy.sh. The topic name is private to you, so keep it to yourself.
3. Send a test notification to check it arrives.

When a machine starts, the reminders are booked on ntfy.sh straight away: one when it should be done, then one every interval for the next 3 hours. Marking it finished cancels the rest. The Emptied it button on the phone notification opens this page and does the same.
